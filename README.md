I'm a **security researcher** focused on **smart contracts and web3**, with a background in offensive security and LLM red-teaming. I go after the bugs that survive audits — **broken access control, accounting & invariant defects, and logic flaws that move real funds** — and I don't report anything without a **runnable proof-of-concept**. Equally comfortable **breaking** systems and **building** the tooling to keep them honest.

<br>

### Focus

- **Smart Contract / DeFi** &nbsp;—&nbsp; Solidity · EVM · access control · accounting & invariant bugs · liquidation / collateral logic · Foundry PoCs
- **Web / AppSec** &nbsp;—&nbsp; IDOR & broken access control · SSRF · auth / identity-verification bypass · business-logic flaws
- **LLM Security** &nbsp;—&nbsp; prompt injection · guardrail bypass · red-teaming RAG & agent systems

<br>

### Selected work

- **[ghostshield](https://github.com/mhsn1/ghostshield)** &nbsp;—&nbsp; an **LLM security scanner** that fires real prompt-injection attacks at a model and reports what gets through. &nbsp;`TypeScript`
- **[ghost-resource-tracker](https://github.com/mhsn1/ghost-resource-tracker)** &nbsp;—&nbsp; detects hidden cryptominers by **power signature** — threat scoring + Shannon entropy. &nbsp;`Python`
- **Open-source security research** &nbsp;—&nbsp; reviewing Google OSS internals ([Timesketch](https://github.com/mhsn1/timesketch) · [GRR](https://github.com/mhsn1/grr)) for security issues.
- **[RabbitHole — THM Writeup](https://github.com/mhsn1/RabbitHole-THM-Writeup)** &nbsp;—&nbsp; hands-on exploitation walkthrough. &nbsp;`CTF`
