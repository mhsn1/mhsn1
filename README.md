I ship **AI systems that are grounded and tested** — chat & voice agents that answer from *your* data with citations (and say *"I don't know"* instead of hallucinating), and the **security tooling** to keep them honest. I'm equally comfortable **building** LLM apps and **breaking** them: I attack models in testing so they don't fail in production.

### Featured work

- **[ai-support-chatbot](https://github.com/mhsn1/ai-support-chatbot)** — RAG assistant that answers from your docs & products **with sources**, and hands off to a human when unsure. &nbsp;`Python · LangChain · GPT/Claude · Vector DB`
- **[ghostshield](https://github.com/mhsn1/ghostshield)** — an **LLM security scanner** that fires real prompt-injection attacks at a model and reports what gets through. &nbsp;`TypeScript`
- **[ghost-resource-tracker](https://github.com/mhsn1/ghost-resource-tracker)** — detects hidden cryptominers by **power signature** — DEFCON-style threat scoring + Shannon entropy. &nbsp;`Python`
