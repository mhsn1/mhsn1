## Hi, I'm Mohsin 👋

I build **AI systems that are grounded and tested** — chatbots, voice agents, and RAG pipelines that answer from *real* data with sources instead of hallucinating, plus the **security tooling** to keep them honest. I think a bot that says *"I don't know"* beats one that lies, and that AI you ship should be **broken in testing before an attacker breaks it in production**.

Comfortable across the stack — Python back-ends, Next.js/React front-ends, and the messy glue that connects LLMs to the real world.

<br>

## 🛠️ What I work on

- **Retrieval-Augmented AI** — chat & voice assistants grounded in your documents, with citations and honest "I don't know" fallbacks.
- **LLM / AI security** — prompt-injection testing, jailbreak red-teaming, and threat detection for AI-adjacent systems.
- **Full-stack delivery** — from vector-DB + FastAPI back-ends to Next.js UIs and Shopify storefronts, shipped clean and documented.
